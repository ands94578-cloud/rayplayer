# 富能量吸取器 · rayplayer

在凡俗世界吸取正能量的日常小器械。你在現實裡真實發生的事——把一件事做完、曬到太陽、幫了人、
忍住沒發火——就是靈氣的來源；記下來，它們會被納進陣裡，累積成看得見的能量與境界。

不是心靈雞湯，是一個把「注意到好事」和「處理壞事」變成日常動作的工具。所有紀錄只存在你自己的
瀏覽器裡，不會上傳任何地方。

> 本器械為情緒與習慣的自我照顧工具，不能取代醫療或心理專業協助。

## 兩個檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | **凡塵能量吸取器**（主程式）——每天在這裡納氣、化煞、調息 |
| `toy.html` | 靈氣採集陣小遊戲——單純好看好玩，主程式底部「打坐一輪」可進去 |

雙擊 `index.html` 即可，無需伺服器、零依賴、可離線使用。

## 三個動作

**納氣**：記一件今天發生的好事。能量源依五行分類，點一下就記進去（+10）。

- 金 · 財氣成就：完成一件事、談成了、有進帳、被肯定、清掉雜物、存下一筆
- 木 · 生機成長：學到新東西、動了身體、曬到太陽、走進大自然、讀了幾頁書、早起了
- 水 · 人和情緒：睡飽了、喝夠水、好好聊了天、幫了人、被人幫、放過一件事
- 火 · 熱情行動：克服了拖延、主動出擊、做了會怕的事、大笑一場、流了汗、說出真心話
- 土 · 安定感恩：感謝一件事、好好吃一頓、陪了家人、整理了環境、靜靜發呆、摸了毛小孩

**化煞**：把卡住你的事寫下來 → 抽一個轉念提問（「這件事裡，哪一分是我真的能動的？」）→
回它一句 → **焚化**（只記下你化過一次煞，內容不留存）或留著。壞事處理完，反而是最大一筆能量（+25）。

**調息**：吸四、屏四、吐六，共四息，約一分鐘的呼吸引導（+15）。

**採氣**（主畫面金色橫條）：**用手機鏡頭真的去掃現實**。相機每一幀都是真訊號——

- **顏色 → 五行**：青綠判木、赤紅判火、黃褐判土、亮白判金、暗藍判水（低飽和時再依明暗分金／土／水）
- **亮度 → 陽氣**：越亮的地方靈氣越足，太暗會告訴你「此處靈氣稀薄」
- **幀差 → 動氣**：畫面有東西在動，氣就活

靈氣粒子會從畫面裡「氣最盛」的格子冒出來（48×36 取樣，八選一錦標賽加權），
所以你對著什麼，就吸到什麼：對著植物是木，對著夕陽是火，對著水泥牆是土。
按住畫面把它們吸進八卦陣心，收功後給一張**此地靈氣報告**（地氣屬性、陽氣、動氣、採得幾縷），
並依採得量換算成當日能量（每 8 縷 1 點，單次上限 40）。

> 需要 https 或 localhost 才能取用相機（瀏覽器規定），而且嵌在別的網頁裡的預覽視窗通常也不給用。
> 最順的用法是把它放上 GitHub Pages，用手機直接開。

**急救**（主畫面紅色橫條）：心裡很亂的時候按這個。三息呼吸（吸四吐六 ×3）先把人穩住 →
用一句話說發生什麼事 → 轉念提問 → 焚化收功（+35）。全程可略過打字，寫下的內容一律不留存。

每日滿陣 60。上方圓陣是今日進度，下方是境界（練氣 → 築基 → 金丹 → 元嬰 → 化神 → 渡劫 → 大乘，
每境九層）、連續天數與 28 天足跡格。

## 本週回顧與晚課提醒

**本週回顧**（修行足跡右上角）：近 7 天的每日長條、與上週的增減、納氣／化煞／調息各幾次、
最常做的一件事、幾天滿陣，以及一段依實際紀錄生成的總評。

**晚課提醒**（頁尾）：設一個時間，每天到點提醒你納氣。分頁開著時會跳系統通知；沒開著也沒關係——
到點之後再打開，頁面上方會出現提醒橫幅。權限與時間都只存在這台裝置。

## 五行會替你看出偏食

近 30 天的五行分佈會指出你哪一行最旺、哪一行最虛，並依**相生**（木生火、火生土、土生金、
金生水、水生木）給出補法。例如火氣虛 → 木生火 → 建議你「學一點新東西」「出去曬個太陽」。
今日心法也是依最虛的那一行挑的，同一天不會變。

用意很簡單：只顧著拚成就（金）、卻從不休息也不聯絡朋友（水）的人，這裡會看得出來。

## 技術

兩支單檔 HTML，原生 JavaScript，零依賴、零建置。

- 紀錄存於 `localStorage`（`fuqi.v1`），全程包在 `try/catch`，隱私模式下也不會壞掉
- 背景靈氣與納氣時的收束光點以 Canvas 2D 繪製，貼圖預先算好，避免逐幀 `shadowBlur`
- 日期一律以本機時區計算（不用 `toISOString()`，那會變成 UTC 日期）；每 30 秒校一次，
  跨午夜會自動換日；連續天數從昨天回推，今天還沒開張不算斷
- 不使用 `confirm()` / `prompt()`（沙箱環境常被封鎖），改為兩段式確認與內嵌對話框
- 採氣以 `getUserMedia` 取後鏡頭，畫面縮到 48×36 後 `getImageData` 做色相／明度／幀差分析，
  每三幀算一次並做指數平滑；離開時確實 `stop()` 所有軌道
- 取樣依 `object-fit: cover` 的裁切換算，格子對得上螢幕上真正看到的畫面
- 相機取不到時分別判斷「嵌在 iframe 裡」「權限被拒」「非安全連線」並給對應說明
- 尊重 `prefers-reduced-motion`，鍵盤可操作，Esc 關閉對話框與採氣圖層

## 部署

丟到任何靜態空間即可。**採氣（相機）功能需要 https，所以建議開 GitHub Pages：**
Settings → Pages → Deploy from branch → 選這個分支與根目錄，等一兩分鐘後用手機開
`https://<你的帳號>.github.io/rayplayer/`，就能真的拿鏡頭去掃了。

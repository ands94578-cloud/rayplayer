# 百家樂路單推演台

手機優先的百家樂路單記錄與推演工具。單一 HTML 檔，無後端、無外部相依（除 Google Fonts），
資料存在瀏覽器本機。

## 先說清楚

八副牌的百家樂，**每一局的結果與前面所有局無關**。牌張消耗造成的機率偏移小於 0.1%，
遠不足以翻轉莊家優勢：

| 下注 | 期望值 |
|---|---|
| 莊 | −1.06% |
| 閒 | −1.24% |
| 和 | −14.4% |

任何路單、纜法或演算法都改不了這三個數字。這個專案的定位是**記錄、推導與驗證**，
不是預言機。回測頁跑個 500 靴就會看到：所有策略的命中率全部收斂在 50% 上下。

## 功能

- **輸入**：底部拇指區三顆大按鈕（莊／閒／和）＋撤銷，可標記莊對／閒對；支援貼上牌路字串
  （`BPPBT`、`莊閒閒莊和`、`庄闲`、`bpt` 都認得）與往返匯出。
- **五路顯示**：珠盤路、大路（含和局斜線、對子角點、龍尾拖右）、大眼仔、小路、曱甴路。
  下三路依標準規則推導，並提供「問路」（假設下一局開莊／開閒，看三路各自變紅或藍）。
- **八組策略即時投票**：理論基準、一階／二階馬可夫、模式比對、跟龍、黏跳判斷、
  問路（下三路）、大路列型。權重依各策略在本靴的**實測命中率**動態調整，每組策略的
  命中數／判定數全程攤在檯面上。
- **本靴續推**：蒙地卡羅模擬估計剩餘局數與莊閒分佈，並可推演一種隨機走勢疊在大路上
  （淡色顯示，標明是樣本之一而非預測）。
- **牌靴回測**：以真實補牌規則模擬 8 副牌整靴（含燒牌、切牌），支援平注、馬丁格爾、
  達朗貝爾、逆纜 1-2-4、1-3-2-6，輸出各策略命中率、累計盈虧曲線與理論期望對照線。

## 檔案

```
src/app.head.html   <title> / 字型 / 樣式
src/app.body.html   版面
src/app.js.html     引擎與互動
build.sh            組出成品
app.html            Artifact 版本（無 <html>/<head>/<body> 外殼）
index.html          可直接開啟或部署的完整網頁
```

改完 `src/` 底下的檔案後執行 `./build.sh` 重新產生 `app.html` 與 `index.html`。

## 在手機上使用

用 Safari 或 Chrome 開啟 `index.html`（或部署後的網址）→ 分享 → 加入主畫面，
即可當成 App 使用，離線可用（字型會退回系統字體）。

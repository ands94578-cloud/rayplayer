# 富能量吸取器 · rayplayer

一個純前端的玄學小玩具：畫面上飄著五行靈氣（金木水火土），按住畫面就會催動八卦吸取陣，
把靈氣捲進陣心。吸夠了「收功結印」，就會依照你納到的五行分佈生成一張**今日能量報告**。

> 純屬娛樂，不構成任何醫療、投資或人生建議。

## 玩法

1. 開啟 `index.html`（雙擊即可，無需伺服器、無任何依賴）。
2. **開光**：輸入姓名／道號與生辰 → 決定你的**本命五行**（本命屬性靈氣較盛，被你所剋的屬性較稀）。
3. **吸取**：按住畫面（桌機也可長按空白鍵）催動吸取陣，滑鼠／手指到哪，陣就到哪。
4. **收功結印**：產出能量報告——主導五行、境界層級、開運色、吉位、旺時、幸運數、五行平衡分與一句籤詩。

## 機制

| 機制 | 說明 |
| --- | --- |
| 五行靈氣 | 粒子分金木水火土五色，吸入哪一種就累積哪一行 |
| 遠場牽引 | 吸取時整個畫面的靈氣會緩緩匯流過來，不會被吸乾 |
| 天地元氣 | 約 2% 機率出現的金色大粒子，一顆抵十餘縷 |
| 心火／走火入魔 | 連吸約 6 秒心火滿溢會強制冷卻三息，需張弛有度 |
| 境界 | 練氣 → 築基 → 金丹 → 元嬰 → 化神 → 渡劫 → 大乘，每境九層 |
| 五行生剋 | 報告會指出最弱的一行，並依「相生」建議該補什麼（如木虛則借水生之） |

同一個姓名 + 生辰 + 同一天 會得到相同的靈氣種子（本命五行、籤詩皆穩定），隔天自動換一輪。

## 技術

單一 `index.html`，原生 Canvas 2D + JavaScript，零依賴、零建置。

- 粒子以預先繪製的徑向漸層貼圖 (`drawImage`) 呈現，避免逐幀 `shadowBlur` 的開銷
- 每幀以半透明底色覆蓋產生拖尾殘影；粒子有速度上限，避免高速穿陣不被判定
- 亂數為 `mulberry32` + FNV-1a 種子雜湊，讓同一組輸入結果可重現
- 支援滑鼠、觸控與鍵盤（空白鍵），DPR 最高 2 倍

## 部署

丟到任何靜態空間即可。GitHub Pages：Settings → Pages → Deploy from branch，選好分支與根目錄即可。
